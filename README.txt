Recommended free hosting: GitHub Pages
--------------------------------------
1. Create a GitHub repository named:
   YOUR-USERNAME.github.io
2. Upload index.html and the complete assets folder.
3. Commit to the main branch.
4. In Settings > Pages, choose deployment from the main branch if Pages is not already enabled.
5. The site will be available at:
   https://YOUR-USERNAME.github.io

Alternative:
Any static host (Netlify, Cloudflare Pages, university web server, etc.) can serve these files directly.
